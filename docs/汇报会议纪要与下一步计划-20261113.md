## 一、会议纪要（定稿）

### 1. Demo 展示情况

华企盾对系统进行了全面演示，涵盖：角色模板套用、处置责任人名录、数据字典（人员类别标签 / 部门风险等级映射 / 行政区划）、规则参数（风险预警规则设置）、脱敏导出策略、审计日志等。

黄工补充：Demo 制作时间较短，细节展示可能不到位，欢迎领导提出意见；会后将整理文档和功能节点发群内供参考（已交付《演示全书-系统讲解与需求映射-V2.2.md》）。

### 2. 领导意见与调整方向（决议）

| # | 决议 | 内容 | 提出人 |
|---|------|------|--------|
| D1 | **系统定位** | 系统定位为**领导决策参考**。数据由公安、信访、卫健等行业主管部门**定期推送**，政法委负责统筹整理；**不面向镇街**作为数据责任主体 | Dndsue |
| D2 | **督办边界** | **暂不设计向镇街下发督办的功能**。仅展示需督办镇街的**趋势或明细**（呈现层面保留，执行层面不做） | Dndsue |
| D3 | **驾驶舱双维度** | 重点人分布需同时以**镇街维度**和**部门（行业主管）维度**呈现，并标明**部门间管理重合人数**（即多部门共同管理同一人的情况） | Dndsue |
| D4 | **风险审批取消** | 政法委**没有审批职能**，风险等级调整由下级部门/行业部门自行修改；政法委只做**统筹与督办**。**审批模块暂不用做**（建议取消设计） | Dndsue |
| D5 | **重点时期盯控** | 同意**暂不深化"安保期重点盯户"功能**，**保留路径即可**；风险研判需依靠行业部门，后续再研究 | 蔡紫鹏 |
| D6 | **导入字段** | 现有字段映射仅为**初步框架**；后续由各行业部门根据实际管理需求（如户籍地/居住地等）提出具体字段要求后再修改 | 张林艳 |
| D7 | **命名修正** | "盲区人群"等名称**不准确，需再斟酌调整** | 张林艳 |
| D8 | **菜单功能说明** | 请华企盾将**左侧菜单每个模块**（预警待办、盲区人群、调整审批、重点时期管控等）的**功能说明形成文档或表格**，供领导层审核并**优化导航命名**；**顶部状态栏**（依据缺失、未指定包联等）也需细化说明 | 蔡紫鹏 |

### 3. 后续安排

2. 领导层将在**下周系统模型跑起来后**，再组织具体沟通。
