## 1 为什么需要这份文档

11 类人员分属四个部门管理，各自有一套分级办法：公安用"高/中/低风险"和"一级/二级/三级/关注对象"，信访用"A/B/C 类"，卫健用危险性评估等级，司法用管理等级。**这些分级口径之间不可比较**——不能直接说"一个高风险等于几个 B 类"。

如果不先把口径统一，会出现三个问题：

1. 驾驶舱的"高风险 486 人"没人说得清是哪几类加起来的；
2. 一人多标时无法判断"就高不就低"到底取哪个；
3. 上级要报表时，同一指标不同部门报出不同数。

所以本文档做一件事：**给每一个"类别+等级"组合赋一个统一的序号（统一风险序），所有比较、筛选、统计都基于这个序号**。各部门原有的分级不变、不取消，只是映射到统一序号上，形成"部门口径"与"区级口径"的对照关系。

## 4 就高不就低

### 4.1 计算规则

人员档案的**管控等级** = 该人所有有效标签中，统一风险序最小（即风险最高）的那个标签的等级。

```
control_rank = min(该人所有 tag_status='有效' 的标签的 std_risk_rank)
control_level = 该 rank 对应的等级名称（字典反查）
```

### 4.2 示例

| 人员 | 标签 1 | 标签 2 | 标签 3 | 管控等级 | 说明 |
|---|---|---|---|---|---|
| A | 涉访 B 类（rank 4） | 严重精神障碍 高风险（rank 2） | 六失一偏 一般关注（rank 6） | **高风险**（rank 2） | 取最高档，并按"高风险"落实措施 |
| D | 社区矫正 低风险（rank 6） | 安置帮教 中风险（rank 4） | — | **中风险**（rank 4） | |
| E | 严重精神障碍 低风险（rank 6） | — | — | **低风险**（rank 6） | 单标签 |
| F | 扬言类 未定级（rank 8） | 涉访 C 类（rank 6） | — | **C 类**（rank 6） | 待核实档不拉高管控等级，但需补定级 |

### 4.3 展示要求

1. 档案页必须**同时展示**：各标签的部门原始等级 + 汇总后的管控等级；
2. 管控等级旁标注来源标签（"因：严重精神障碍-高风险"），避免经办人困惑；
3. 列表页默认显示管控等级，可切换显示"各标签等级"；
4. 驾驶舱所有"高风险"口径均基于管控等级，不基于标签等级，避免重复计数。

## 5 双在册判定

### 5.1 定义

同一自然人（同一身份证号），同时被两个及以上部门列入台账。

### 5.2 分类

| 类型 | 判定条件 | 是否计入"双在册"专项统计 |
|---|---|---|
| 公安卫健双在册 | 严重精神障碍患者标签同时存在于公安、卫健两个来源 | ✅ 计入 |
| 公安信访双在册 | 涉访关注人员标签同时存在于公安、信访两个来源 | ✅ 计入 |
| 其他跨部门重号 | 如司法 + 公安、卫健 + 信访 | 记录，但不单独统计，归入"多部门在册" |

### 5.3 关键区分：双在册 ≠ 多重标签

这是最容易混淆、导致统计重复的地方，必须区分清楚：

| 情形 | 标签数 | 双在册 | 多重标签 | 说明 |
|---|---|---|---|---|
| 精神障碍患者，公安和卫健都有 | **1** | ✅ | ❌ | 同一类别跨部门在册，标签仍是同一个 |
| 涉访人员，公安和信访都有 | **1** | ✅ | ❌ | 同上 |
| 既是精神障碍患者，又是涉访人员 | 2 | ✅ | ✅ | 两个不同类别 |
| 仅卫健在册的精神障碍患者 | 1 | ❌ | ❌ | 单部门单标签 |

**统计规则**：双在册看"部门数"，多重标签看"类别数"。两个标识独立计算，可以同时为真。

### 5.4 双在册的管理要求

1. 系统自动置 `dual_reg_flag`，并在档案、列表、驾驶舱统一显示；
2. 双在册人员的管控等级同样按"就高不就低"；
3. 生成"双部门确认任务"：两个部门各需确认一次，任一方未确认则进入待办；
4. 双在册人员**不得**由任一部门单方消减，需双方确认后方可移出双在册清单（可仍保留在某部门台账内）。

## 6 多重标签规则

### 6.1 标签上限

| 标签数 | 处理 |
|---|---|
| 1—3 | 正常，自动合并 |
| 4 及以上 | 需主管部门审批通过后允许，系统拦截直录；审批通过后进入"重点多重标签人员"清单 |
| 超过 6 | 需政法委专题研判，并说明标签重复认定原因 |

上限设计的逻辑：会议明确"原则上一人最多三个标签"。上限不是技术限制，而是**管理约束**——标签过多往往反映部门间认定口径重叠，需要通过研判厘清，而不是无限叠加。

### 6.2 标签组合研判

系统支持按标签组合分析，用于发现"跨部门共管盲区"：

- 同时含 A 和 B（交集）
- 含 A 不含 B（差集）
- 仅含 A（单一标签人群）

**重点关注组合**（建议在驾驶舱单列）：
- 涉访 + 严重精神障碍
- 涉访 + "六失一偏"
- 严重精神障碍 + "六失一偏"
- 涉访 + 严重精神障碍 + "六失一偏"（三重叠加）

这三类组合的共同特征：跨政法、卫健、民政多条线，最易出现"都管一点、都不全管"。

## 7 风险等级调整规则

### 7.1 上调（风险升高）

| 项 | 规则 |
|---|---|
| 触发 | 部门研判、属地报告、新发案事件、公安推送、走访发现异常 |
| 审批 | **立即生效，事后备案**（24 小时内补录依据与审批） |
| 理由 | 风险升高时优先保证管控到位，不能让流程耽误措施 |
| 留痕 | 必须记录：发起人、时间、依据、备案审批人 |
| 通知 | 自动通知主责部门、属地包联干部 |

### 7.2 下调（风险降低）

| 项 | 规则 |
|---|---|
| 触发 | 实地走访、专业评估、治疗稳定、信访事项化解、矫正期满等 |
| 审批 | **必须先审批后生效**，主管部门审批 |
| 依据 | 必填评估依据 + 至少 1 个附件（走访记录、诊断材料、研判意见、化解文书） |
| 降幅 | 原则上单次只降一档；跨两档下降需政法委复核 |
| 频次 | 同一人员 30 日内不得重复下调；同一标签 90 日内下调不超过 1 次 |
| 冷却 | 下调后 30 日内无随访记录，自动生成预警 |

### 7.3 审批层级

| 调整类型 | 审批人 |
|---|---|
| 低风险 ↔ 中风险 | 主管部门科室负责人 |
| 中风险 ↔ 高风险 | 主管部门分管领导 |
| 高风险 → 次高档（如高风险降为中风险） | 主管部门分管领导 + 政法委备案 |
| 个人极端 / A 类 / 一级 的降级 | 政法委分管领导 |
| 涉未成年人等级调整 | 额外增加未保部门会签 |

### 7.4 变动留痕要求

每条变动记录须包含：人员、标签、原等级、新等级、调整类型（上/下）、原因、依据附件、申请人、申请时间、审批人、审批时间、生效时间、备案编号。该记录**不可修改、不可删除**，是追责依据。

## 8 新增与消减规则

### 8.1 新增

| 项 | 规则 |
|---|---|
| 必备要素 | 身份证号、姓名、责任镇街、来源部门、类别、等级、列入原因、列入时间 |
| 依据 | 需有认定材料（判决书、诊断书、查获记录、受理记录等） |
| 审批 | 由来源部门经办提交，主管部门确认 |
| 去重 | 导入时按身份证号自动查重；已存在则合并为新增标签，不新建档 |
| 已消减人员再出现 | **恢复原档案**（状态置回在册），不新建档，保留历史记录 |

### 8.2 消减

| 消减原因 | 适用 | 证明材料 |
|---|---|---|
| 期满解除 | 矫正期满、帮教期满、戒毒康复期满 | 解除文书 |
| 迁出 | 户籍与居住地均迁出本区 | 迁出证明 |
| 死亡 | — | 死亡证明或公安核对结果 |
| 撤管 | 经研判不再属于该类管理对象 | 研判意见 + 审批 |
| 转其他类别 | 如安置帮教转为社区矫正 | 转换依据（原档案保留，新增标签） |

**规则**：
- 消减必须审批，且需注明原因；
- 消减后档案不物理删除，置 `status='已消减'`，退出所有统计口径；
- 双在册人员消减需两个部门共同确认（见 5.4）；
- 消减人员如需查询，走"已消减"筛选，且需专门权限。

### 8.3 跨区流动

会议提到"风险地区流动原因记录要求"。规则：

| 流向 | 处理 |
|---|---|
| 外省市来京（入区） | 标注来源地区、来京时间、在京住所性质、有无监护人；"三无"人员（无固定住所、无稳定职业、无明确监护人）单列，由民政、公安、卫健联合研判 |
| 本区流出 | 记录流向地区、时间，档案置"已迁出"，不移交数据（数据不出域） |
| 区内跨镇街流动 | 责任镇街变更，包联干部随之调整，留痕 |

## 9 特殊情形处理

| 情形 | 处理规则 |
|---|---|
| 风险不详（拒访、失访） | rank 8，单列"待核实"；不参与高风险统计；**必须**进入预警（失访超 30 日升级预警） |
| 未定级 | rank 8，要求 30 日内补定级，逾期预警 |
| 评估依据缺失 | 允许入库但标记；**限制其等级上调以外的操作**（无依据不得降级） |
| 无身份证号 | 临时编号 `TMP-镇街码-序号`，不参与去重率计算，单列待补 |
| 同名不同人 | 绝不合并；档案页提示"存在同名人员 N 人"，避免经办人认错 |
| 一人多重身份证号 | 以公安核定为准，历史号记入备注，避免二次建档 |
| 未成年人 | 标签页加"涉未成年人"标记，访问日志单独审查，导出需额外审批 |
| 港澳台/外籍 | 用通行证/护照号作唯一键，单列统计 |

## 10 重点时期管控规则

### 10.1 响应等级

| 响应等级 | 触发 | 走访频次要求 | 报告要求 |
|---|---|---|---|
| 三级（日常） | 平时 | 高风险每月 ≥1 次，中风险每季 ≥1 次，低风险每半年 ≥1 次 | 月度报送 |
| 二级（加强） | 重点时期前 30 日，或发生重大案事件后 | 高风险每半月 ≥1 次 | 周报 |
| 一级（战时） | 全国两会、国庆、重大庆典期间 | **高风险及以上每日见面** | **每日零报告** |

### 10.2 系统支撑

1. 重点时期由政法委在系统配置起止日期与响应等级，到期自动回落；
2. 一级响应期间自动生成"应见名单"（高风险及以上 + 辖区），属地每日回填见面状态；
3. 未报告人员次日 9:00 自动生成"应见未见"清单，推送属地与主管部门；
4. 零报告可通过界面一键提交（当日应见人数、已见人数、异常情况），无需逐人填表。

### 10.3 走访记录必填项

走访时间、方式（上门/电话/约谈/联合走访）、走访人、见到本人与否、精神与行为状态、发现的问题、已采取措施、下一步措施、是否需要上报。

## 11 统计口径定义

所有对外报表、驾驶舱指标必须使用以下口径，不得各自定义。

| 指标 | 定义 | 计算方式 |
|---|---|---|
| 台账记录数（人次） | 各部门报送的原始台账记录条数 | `raw_ledger` 有效记录数 |
| 重点人员总数（人头） | 去重后的自然人数 | `person WHERE status='在册'` 计数 |
| 高风险及以上人数 | 管控等级 rank ≤ 2 | `control_rank <= 2` |
| 风险较高及以上人数 | 管控等级 rank ≤ 4（对应报告口径"高中风险、AB类、一二级、重点关注"） | `control_rank <= 4` |
| 双在册人数 | `dual_reg_flag = true` | 独立计数 |
| 多重标签人数 | `tag_count >= 2` | 独立计数 |
| 三重及以上标签人数 | `tag_count >= 3` | 独立计数 |
| 待核实人数 | `control_rank >= 7` | 单列，不计入高风险 |
| 本月新增 | 本月 `first_reg_date` 或新增标签的人数 | 按首次建档时间 |
| 本月消减 | 本月状态变更为已消减的人数 | 按 `reduce_date` |
| 应见人数 | 一级响应期间辖区内高风险及以上人数 | 按响应等级计算 |
| 应见未见人数 | 应见人数 − 当日已回填见面人数 | 每日 9:00 计算 |
| 依据缺失人数 | 存在标签但 `eval_basis` 为空的人数 | 单列，用于督促补录 |
| 标签重合率 | 标签总数 ÷ 在册人数 | 反映重复认定程度 |

### 11.1 口径冲突处理原则

1. 与报告口径不一致时，**以报告口径为准**并调整系统（本文件第 3.2 节为唯一来源）；
2. 部门坚持自己的口径时，系统保留部门口径作为"部门视图"，区级统计一律用统一口径；
3. 任何口径变更须书面确认，系统以字典版本管理，历史报表按变更时点口径可复算。
