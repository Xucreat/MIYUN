- 根因：角色只存 sessionStorage，`target="_blank"` 新标签不继承；大屏页（bigscreen.html 无 store.js，有「返回工作台」→ dashboard.html）在无会话存档的标签里 STORE 按默认 admin 初始化。
- `store.js`：新增 `ROLE_KEY = 'miyun-demo-v2:role'` localStorage 镜像。`load()` 在无 sessionStorage raw 时从镜像恢复角色；`setRole()` 双写；`reset()` 清镜像。
- 同类入口一并覆盖：dashboard「投屏模式」、index.html 大屏链接、page-alerts/page-blind 新开 system.html / risk.html 的 target=_blank 深链。

## 踩坑
- 我改 load() 时引用了 try 块内的 `const raw`（块级作用域）→ 页面报 `raw is not defined` 全站崩；探针 diag1 抓到后改为 `let raw = null` 提到 try 外。探针先行验证再次立功。
- 探针误判两次：U.select 弹层 `.ui-pop` 为 fixed 定位，`offsetParent !== null` 过滤会误杀；`document.querySelector('.ui-pop')` 会命中顶栏搜索的空 pop——取「最后一个带 .op 的 .ui-pop」才对。
