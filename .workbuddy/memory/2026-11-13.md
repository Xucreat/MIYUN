# 同日追加（第十二批：全站 SPA 化 · 点击模块仅切换内容区，导航零刷新）

## 需求
用户反馈：点击功能模块后整页跳转，侧栏/顶栏重新渲染出现"刷新感"；且部分链接 target=_blank 开新页签。要求：首页点击模块后仅在当前页切换内容，不再出现多个页签。方案 A（真 SPA 化）经确认后实施。

## 实现
- **assets/router.js（新增 ~170 行）**：document capture 级委托拦截所有同源 *.html 内链（含动态渲染与 target=_blank 的内链；data-ext / bigscreen / login / index 除外）。`go(url)`：teardown → fetch → DOMParser → 替换页面私有 `<style data-router>`、body data-*、body.className（全站恒 fit）、`.content` innerHTML、document.title → pushState（**先于**页面脚本执行，因 persons?tab=query 等读 location.search）→ PAGE_GATE/SHELL_REFRESH/SYNC_METRICS/applyPermGates → 页面脚本按原顺序串行重建（src 等 onload 链、内联同步）。任何异常兜底 `location.href` 整页回退，永不白屏。popstate 支持前进/后退。
- **assets/shell.js 重构**：页面元数据抽出 `meta()` 函数；侧栏 nav-item 加 `data-nav-id`；顶栏拆为一次构建（搜索框/事件监听不动）+ `#tbNav` 面包屑与 `#topActs` 按钮组可重刷；新增 `window.SHELL_REFRESH`（侧栏高亮/面包屑/页头按钮搬移可重复执行）、`window.PAGE_GATE`（权限门改可重入：先清 page-denied/page-deny 再判定）；`#tbNav:empty{display:none}` 防空分隔线；搜索框选择与 openPerson 改走 ROUTER.go（回退 location.href）；`window.__searchClose` 供路由收起搜索弹层。
- **assets/store.js**：新增导出 `clearSubs()`（listeners.length=0）。页面脚本经 `S.on()` 注册的监听引用已脱离 DOM 的节点，SPA 换页不清会在后续 commit 时对 null 渲染报错（实测 page-system renderHash / page-approval renderList 三连炸）。shell/ui 无订阅，全清安全。

## 踩坑（关键）
- **经典脚本重复执行的顶层声明陷阱**：再次执行含顶层 const/let/function 的 classic script 会抛 `Identifier already declared`（全局词法环境不随页面切换清空）。page-*.js 全部 IIFE 包裹天然安全；**dashboard.html 内联脚本 38 个顶层声明未包裹**，二次进入必炸。解法：router 对内联脚本统一包 `(function(){...})()`——前置审计确认全站无 HTML 属性内联事件、无跨脚本全局符号依赖，包裹零副作用。
- Playwright `framenavigated` 会把 pushState 同文档导航也计入，"0 整页导航"断言改用 window 标记存活法（首次加载打 `__SPA_ALIVE` 标记，跑完全程仍存活 = 无整页重载）。
- body.fit 模式下 innerText 只含可见文本，内容量断言必须用 innerHTML。
